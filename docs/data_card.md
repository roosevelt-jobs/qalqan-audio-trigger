# Data card

Каждый датасет проверяется по CLAUDE.md 7.2 до написания загрузчика. «Не проверено» — значит не
проверено, а не «скорее всего так».

## FSD50K (eval)
- Источник (оригинал): Fonseca et al., «FSD50K: An Open Dataset of Human-Labeled Sound Events»,
  IEEE/ACM TASLP 2022; Music Technology Group, Universitat Pompeu Fabra. Клипы — из Freesound.
- Откуда скачан: Zenodo, DOI 10.5281/zenodo.4060432 (запись авторов; копии на Hugging Face —
  перезаливки без авторов, не используются).
- Версия / дата скачивания: 1.0 (запись Zenodo обновлена 2022-04-24), скачано 2026-10-27.
  md5 файлов из записи Zenodo — `data/fsd50k/raw/expected.md5`.
- Лицензия: набор целиком — CC BY 4.0; у каждого клипа своя лицензия от автора на Freesound
  (`eval_clips_info_FSD50K.json`). Eval: CC0 — 4914, CC BY — 3489, CC BY-NC — 1425,
  CC Sampling+ — 403. **CC BY-NC запрещает коммерческое использование** — [CHECK] перед любым
  коммерческим применением.
- Языки: не применимо (звуковые события); речь в клипах на разных языках.
- Объём: eval — 10 231 клип, 27,9 ч, средняя длина 9,8 с (README авторов).
- ID дикторов: дикторов как таковых нет; есть автор записи на Freesound (`uploader`):
  2297 разных в eval. По README авторов dev и eval не пересекаются по авторам.
- Предварительная аугментация: не найдена. Проверено по звуку всех 10 231 клипов: 2 пары точных
  дубликатов (повторные загрузки одного автора: 391445/391449 «Ukulele Whoosh», 409234/409236
  «rip long»; обе — негативы, к крику не относятся); совпадения по длине и огибающей громкости
  оказались разными звуками (короткие клипы), а не копиями.
- Разметка: ручная проверка людьми, метки на весь клип (без времени начала/конца события),
  метки распространены вверх по онтологии AudioSet (например, Yell → Shout → Human_voice).
- Исходный формат → приведён к: PCM 16 бит, 44,1 кГц, моно (проверено у всех 10 231 клипов,
  27,85 ч) → 16 кГц моно PCM 16 бит в `data/processed/fsd50k_eval/` (librosa, soxr_hq).
- Целостность: md5 всех 5 архивов совпали с записью Zenodo; в архиве аудио только `.wav`
  (10 231 файл, одна папка), CRC всех файлов архива сошлись.
- Назначение в проекте: **тест детектора B** (крик и возглас). Позитивы — клипы с Screaming,
  Shout или Yell; исключены как спорные — Crying_and_sobbing, Cheering, Crowd (если в клипе нет
  крика); остальное — негативы.
- Известные проблемы:
  - не условия бейджа: записи часто домашние или студийные, крики бывают сыграны;
    FRR по условиям из раздела 6 не посчитать;
  - разметка на весь клип: попаданием считается любая тревога в файле;
  - негативы — короткие разнородные клипы, FA/h на них лишь приблизительно отражает реальный поток.
